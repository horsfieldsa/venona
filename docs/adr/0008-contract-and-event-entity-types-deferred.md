# 2026-08-04 — `Contract` and `Event` entity types deferred


Neither has a stable canonical surface. An article says `"$99M OTA"`, tomorrow's
says `"the $99 million agreement"`, and the C4 slug rule mints two entities. A
live probe produced exactly that.

They return when there is a PIID-based identity rule. Adding them later is
additive: a new ontology entry, a colour token, and seed examples.
