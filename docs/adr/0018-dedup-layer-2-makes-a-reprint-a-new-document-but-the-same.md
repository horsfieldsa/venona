# 2026-08-04 — Dedup layer 2 makes a reprint a new DOCUMENT but the same CLUSTER


A wire story republished by a second outlet is genuinely a separate,
separately-addressable article, so it gets its own document row. But it must
join the *existing* cluster, because clusters are the downstream unit — five
outlets carrying one story is one brief item whose pickup count is its salience
signal, not five items.

Getting this backwards in either direction is bad: one cluster per document
lets a wire story dominate a brief, and dropping the duplicate document loses
the pickup count that makes it rank.
