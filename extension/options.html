Which Venona domain this extension reads from. Each one keeps its own access on this machine.

The server address. Ends in /api. Any other host works too; saving it asks the browser for permission to reach it, which localhost already has.

Filled in by Connect with Google, or pasted from uv run venona mcp token new --label "extension" --scope annotate. Stored on this machine only, never synced. Either way it can show Venona's reading and list the covered sites, and nothing more: it cannot start anything, change anything, or spend anything.

Connect another domain

Add a domain by hand and point it at its address above, or browse the directory. Each one connects separately.

The directory lists every domain its publisher runs. Browsing asks the browser for permission to reach it; adding one asks for that server's host. Each added one still connects separately above.
